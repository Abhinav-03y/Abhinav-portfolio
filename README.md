# Abhinav Yadav — Personal Portfolio

## 📌 About the Project

This is my personal portfolio website created as part of my CSS Portfolio Challenge.

The portfolio showcases my introduction, technical skills, projects, and contact information through a responsive and user-friendly web interface.

## ✨ Features

- Responsive portfolio design
- Personal introduction section
- About Me section
- Technical Skills section
- Project showcase
- Contact form
- Responsive navigation
- Interactive hover effects
- Form focus states
- Consistent custom theme
- Mobile, tablet, and desktop support

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Variables
- Flexbox
- CSS Grid
- Media Queries
- Git
- GitHub

2. Open the project folder.
3. Open `index.html` in a browser.
4. Alternatively, use Live Server in VS Code.
